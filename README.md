# CorrectMode(CorrectModeWidget)

Android 16 / 17 向けの、**マナーモード(着信音/バイブ/ミュート)** と **DND(サイレントモード)** の組み合わせをウィジェットで切り替えるアプリです。自分専用のデバッグAPKをGitHub Actionsでビルドして使います。**商用利用禁止・再配布禁止**(LICENSE参照)。

An Android 16/17 widget app that switches combinations of **Ringer mode** (ring / vibrate / mute) and **DND** (Do Not Disturb). Personal-use debug APK built by GitHub Actions. **No commercial use, no redistribution** (see LICENSE).

## 用語(取り違え防止)

「サイレントモード」は日本語ではDND、英語の「Silent mode」は着信音のミュート/バイブを指し、非常に紛らわしいため、このアプリでは次の2語だけを使います。

| このアプリの語 | 意味 | 選択肢 |
|---|---|---|
| **マナーモード** (Ringer mode) | 音量キーの着信音/バイブ/ミュート | 🔔 着信音 / 📳 バイブ / 🔕 ミュート |
| **DND** (Do Not Disturb) | Androidの「サイレントモード」 | ✅ オフ(音あり) / 🔉 通知フィルタ(音声を許可) / 🚫 オン(すべて音なし) |

「アラームのみ」は独立した選択肢ではなく、**通知フィルタでアラームとメディアだけ許可した状態**です(古いデータは自動で変換されます)。

**プロファイル** = マナーモードとDNDの組み合わせ1つ(+通知フィルタで許可するもの、自動解除、タイマー、ウィジェットの見た目)。

## 使い方

- メイン画面は2つのタブ(名前は長押しで変更)
  - **左(自分用)**: 自分のプロファイル(初回は「汎用サンプル」「常に無音」「おやすみ中(+緊急)」の3つ)。「追加」から、質問に答えて作る / 自分で設定する / テンプレートから選ぶ、のどれかで作成
  - **右(テンプレート)**: ひな形8種(同じ挙動のものは1つにまとめてあります。すべての組み合わせではありません)。編集でき、編集画面の「初期化」で元に戻せます
- プロファイル一覧のチップは、上の段が音の種類(📞通話 💬メッセージ…)、下の段がその鳴り方(✅鳴る 📳振動のみ ✖鳴らない…)
- プロファイルの **アイコンをタップ=オン/オフ**、**カードをタップ(または長押し)=編集**。右の▲▼で並べ替え
- **ウィジェット2種**(サイズ変更可)
  - トグル(1x1): プロファイルを順に切り替え、最後でオフ
  - 切り替え: 選んだプロファイルのボタンを並べ、タップで切り替え。オン中のものをタップで解除。ウィジェットを広げると、ボタンが正方形に近くなるよう自動で段に折り返します(段の並びは上が多く、少ない段は中央)
  - 設置時の設定画面で、プロファイルの並び順(▲▼)と、切り替えウィジェット全体の背景色・不透明度を決められます
  - タップ直後の連打防止中は、ボタンがグレーになります。エラーが残っている間は ⚠ が表示されます
- **通知フィルタ(音声を許可)で通すもの**: 通話・メッセージの相手、メディア、アラーム、システム音(操作音)、リマインダー、カレンダーの予定。指定しない項目は**すべてオフ**。許可するアプリはAndroid側の設定(全プロファイル共通)で選びます
- **Bluetoothイヤホン接続中だけメディアを許可**(切断で自動的に戻す)
- **自動解除**(30分・1時間・2時間・自由入力・期限なし・毎回選ぶ)と、**タイマーでの自動オン**(開始時刻・終了時刻・曜日)
- ウィジェットのタップ時に**振動**するかどうかをプロファイルごとに設定
- 解除すると、オンにする前のマナーモード・DND設定に戻します。プロファイルごとに「解除したらすべて解除(通常の着信音・DNDオフ)」や、音量の復元も選べます
- オン中の通知から、解除までの時間と、次の自動オンの時刻を変更できます
- 見た目は別ウィンドウで編集します(オフ時 / オン時 / 形・余白のタブ、プレビューは常に表示)。アイコンは組み込みのフラットアイコン、絵文字、または好きな画像(オン時だけ別のアイコン・画像も可)。背景色と不透明度・アイコン色・形(円・カプセル/大きな角丸/角丸/四角)・比率維持・外側の余白・名前表示を変更可。ダークテーマ対応
- 言語: システム / 日本語 / English(設定で変更)
- 全設定のエクスポート/インポート(JSON)。失敗の理由は画面(トースト・「診断」欄)に表示

### 音の出方の注意

- マナーモードを「バイブ」「ミュート」にしても、**アラームとメディア(動画・音楽)の音は鳴ります**。消すには、DNDを「通知フィルタ(音声を許可)」にして、アラーム・メディアを許可しない設定にします
- DNDを使うと、**許可していない通知は振動も止まります**。バイブで知らせたい相手は「通話」「メッセージ」で許可してください。「ミュート」では、許可した相手でも音も振動もありません
- 「オン(すべて音なし)」は**アラームも鳴りません**。アラームだけ鳴らしたいときは、通知フィルタでアラームだけ許可します
- 「バイブ + オン(すべて音なし)」と「ミュート + オン(すべて音なし)」は同じ挙動です(Androidがマナーモードを上書きするため)

## アプリのアイコンを変える

[icon/](icon/README.md) に `icon.svg` または `icon.png` を置いて push すると、ビルド時にランチャーアイコンへ変換されます(失敗しても標準アイコンのままビルドは成功)。ウィジェット選択画面のアイコンは、任意で `icon/widget_preview.png`(正方形・透過可・512×512px)を置くと使われます。

## 権限

| 権限 | 用途 |
|---|---|
| ACCESS_NOTIFICATION_POLICY | DND・着信音の操作(設定画面で許可) |
| BLUETOOTH_CONNECT | Bluetooth音声機器の検出 |
| POST_NOTIFICATIONS | オン中の通知 |
| SCHEDULE_EXACT_ALARM | 正確な自動解除・タイマー(なくても動作し、数分遅れる場合あり) |
| RECEIVE_BOOT_COMPLETED | 再起動後に自動解除・タイマーを再登録 |
| VIBRATE | ウィジェットのタップ時の振動 |

INTERNET権限はありません。データはすべて端末内です。

## 開発者向け

- **ビルド**: `main` へのpushでGitHub Actionsがデバッグ APKをビルドし、Artifacts に `CorrectModeWidget-build<番号>-debug.apk` を置きます。成果物は直近2つだけ残し、古いものは自動で削除します。バージョン表示はビルド番号Nから `1.0.(N÷100).(N÷100の余り)`(例: #1010 → v1.0.10.10)。`docs/`・`*.md`・`*.txt`・`LICENSE` だけの変更ではビルドしません。
- **署名**: リポジトリ内の固定デバッグ鍵(`app/debug.keystore`、パスワード `android`)。更新インストールが毎回できます。**公開鍵なので配布・リリースには使わないでください。**
- **構成**: Kotlin、外部ライブラリなし、画面はコードで構築(XMLレイアウトはウィジェットのみ)。`Engine.kt` が状態機械(変更前に保存 → 消音側を先に変更 → 読み戻して確認 → 失敗なら元に戻す)。`Schedules.kt` がタイマー、`Backup.kt` がエクスポート/インポート。
- **消音の安全策**: 外部変更は上書きしない、通知チャンネルは無音、Bluetooth切断は即時に除外。詳細と点検結果は [docs/REVIEW.md](docs/REVIEW.md)。
- **未確認(実機で要確認)**: Android 16/17でのDNDの挙動、許可した着信がバイブのみで届くか、メーカー独自の省電力による受信機の停止、振動(ウィジェットタップ時)が鳴るか。[docs/REVIEW.md](docs/REVIEW.md) を参照。

## 秘匿情報の方針 / Secrets policy
- 現在、APIキー・トークン・パスワード等の秘匿情報はリポジトリに入れていません(署名鍵は公開前提のデバッグ用 `debug.keystore`、パスワード `android`)。
- 今後、秘匿が必要な情報(APIキー、トークン、リリース用署名鍵など)を扱う段階になったら、アプリ完成後にリポジトリを **プライベートへ移行** してから変更し、値はGitHub Actionsの Secrets に置きます。コードには書きません。
