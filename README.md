# CorrectMode(CorrectModeWidget)

Android 16 / 17 向けの、**着信音(音あり/バイブ/ミュート)** と **DND(サイレントモード)** の組み合わせをウィジェットで切り替えるアプリです。自分専用のデバッグAPKをGitHub Actionsでビルドして使います。**商用利用禁止・再配布禁止**(LICENSE参照)。

An Android 16/17 widget app that switches combinations of **Ringer** (sound / vibrate / mute) and **DND** (Do Not Disturb). Personal-use debug APK built by GitHub Actions. **No commercial use, no redistribution** (see LICENSE).

## 用語(取り違え防止)

「サイレントモード」は日本語ではDND、英語の「Silent mode」は着信音のミュート/バイブを指し、非常に紛らわしいため、このアプリでは次の2語だけを使います。

| このアプリの語 | 意味 | 選択肢 |
|---|---|---|
| **着信音** (Ringer) | 音量キーの音あり/バイブ/ミュート | 音あり / バイブ / ミュート |
| **DND** (Do Not Disturb) | Androidの「サイレントモード」 | オフ / 優先のみ / アラームのみ / すべてブロック |

**プロファイル** = 着信音とDNDの組み合わせ1つ(+優先のみで通すもの、自動解除、タイマー、ウィジェットの見た目)。

## 使い方

- メイン画面は2つのタブ(名前は長押しで変更)
  - **左(自分用)**: 自分のプロファイル。「追加」から、質問に答えて作る / 自分で設定する / 基本パターンから選ぶ、のどれかで作成
  - **右(全パターン)**: 着信音とDNDの基本パターン8種(同じ挙動のものは1つにまとめてあります)。編集でき、編集画面の「初期化」で元に戻せます
- プロファイルの **アイコンをタップ=オン/オフ**、**カードをタップ(または長押し)=編集**。右の▲▼で並べ替え
- **ウィジェット2種**(サイズ変更可)
  - トグル(1x1): プロファイルを順に切り替え、最後でオフ
  - 切り替え(1xN): 選んだプロファイルのボタンを並べ、タップで切り替え。オン中のものをタップで解除
- **「優先のみ」で通すもの**: 通話・メッセージの相手、メディア、アラーム、システム音、リマインダー、カレンダーの予定。指定しない項目は**すべてオフ**。通すアプリはAndroid側の設定(全プロファイル共通)で選びます
- **Bluetoothイヤホン接続中だけメディアを許可**(切断で自動的に戻す)
- **自動解除**(30分・1時間・2時間・自由入力・期限なし・毎回選ぶ)と、**タイマーでの自動オン**(開始時刻・終了時刻・曜日)
- ウィジェットのタップ時に**振動**するかどうかをプロファイルごとに設定
- 解除すると、オンにする前の着信音・DND設定に戻す。プロファイルごとに音量の復元も選べます
- アイコンは組み込みのフラットアイコン、絵文字、または好きな画像。背景色(なし/透明、自由な色も可)・アイコン色・形・大きさ・名前表示を変更可。ダークテーマ対応
- 言語: システム / 日本語 / English(設定で変更)
- 全設定のエクスポート/インポート(JSON)。失敗の理由は画面(トースト・「診断」欄)に表示

### 音の出方の注意

- 着信音を「バイブ」「ミュート」にしても、**アラームとメディア(動画・音楽)の音は鳴ります**。消すにはDNDの「優先のみ」で、アラーム・メディアを許可しない設定にします
- DNDを使うと、**許可していない通知は振動も止まります**。バイブで知らせたい相手は「着信・メッセージ」で許可してください
- 「すべてブロック」は**アラームも鳴りません**。アラームだけ鳴らしたいときは「アラームのみ」か、優先のみでアラームだけ許可します
- 「バイブ + すべてブロック」と「ミュート + すべてブロック」は同じ挙動です(Androidが着信音の設定を上書きするため)

## アプリのアイコンを変える

[icon/](icon/README.md) に `icon.svg` または `icon.png` を置いて push すると、ビルド時にランチャーアイコンへ変換されます(失敗しても標準アイコンのままビルドは成功)。ウィジェット選択画面のアイコンは、任意で `icon/widget_preview.png`(正方形・透過可・512×512px)を置くと使われます。

## 権限

| 権限 | 用途 |
|---|---|
| ACCESS_NOTIFICATION_POLICY | DND・着信音の操作(設定画面で許可) |
| BLUETOOTH_CONNECT | Bluetooth音声機器の検出 |
| POST_NOTIFICATIONS | オン中の通知 |
| SCHEDULE_EXACT_ALARM | 正確な自動解除・タイマー(なくても動作し、数分遅れる場合あり) |
| RECEIVE_BOOT_COMPLETED | 再起動後に自動解除・タイマーを再登録 |
| VIBRATE | ウィジェットのタップ時の振動 |

INTERNET権限はありません。データはすべて端末内です。

## 開発者向け

- **ビルド**: `main` へのpushでGitHub Actionsがデバッグ APKをビルドし、Artifacts に `CorrectModeWidget-build<番号>-debug.apk` を置きます。`docs/`・`*.md`・`*.txt`・`LICENSE` だけの変更ではビルドしません。
- **署名**: リポジトリ内の固定デバッグ鍵(`app/debug.keystore`、パスワード `android`)。更新インストールが毎回できます。**公開鍵なので配布・リリースには使わないでください。**
- **構成**: Kotlin、外部ライブラリなし、画面はコードで構築(XMLレイアウトはウィジェットのみ)。`Engine.kt` が状態機械(変更前に保存 → 消音側を先に変更 → 読み戻して確認 → 失敗なら元に戻す)。`Schedules.kt` がタイマー、`Backup.kt` がエクスポート/インポート。
- **消音の安全策**: 外部変更は上書きしない、通知チャンネルは無音、Bluetooth切断は即時に除外。詳細と点検結果は [docs/REVIEW.md](docs/REVIEW.md)。
- **未確認(実機で要確認)**: Android 16/17でのDNDの挙動、許可した着信がバイブのみで届くか、メーカー独自の省電力による受信機の停止。[docs/REVIEW.md](docs/REVIEW.md) を参照。

## 秘匿情報の方針 / Secrets policy
- 現在、APIキー・トークン・パスワード等の秘匿情報はリポジトリに入れていません(署名鍵は公開前提のデバッグ用 `debug.keystore`、パスワード `android`)。
- 今後、秘匿が必要な情報(APIキー、トークン、リリース用署名鍵など)を扱う段階になったら、アプリ完成後にリポジトリを **プライベートへ移行** してから変更し、値はGitHub Actionsの Secrets に置きます。コードには書きません。
