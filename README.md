# CorrectMode(CorrectModeWidget)

Android 16 / 17 向けの、**着信音(音あり/バイブ/ミュート)** と **DND(サイレントモード)** の組み合わせをウィジェットで切り替えるアプリです。自分専用のデバッグAPKをGitHub Actionsでビルドして使います。MITライセンス。

An Android 16/17 widget app that switches combinations of **Ringer** (sound / vibrate / mute) and **DND** (Do Not Disturb). Personal-use debug APK built by GitHub Actions. MIT licensed.

## 用語(取り違え防止)

「サイレントモード」は日本語ではDND、英語の「Silent mode」は着信音のミュート/バイブを指し、非常に紛らわしいため、このアプリでは次の2語だけを使います。

| このアプリの語 | 意味 | 選択肢 |
|---|---|---|
| **着信音** (Ringer) | 音量キーの音あり/バイブ/ミュート | 音あり / バイブ / ミュート |
| **DND** (Do Not Disturb) | Androidの「サイレントモード」 | オフ / 優先のみ / アラームのみ / すべてブロック |

**プロファイル** = 着信音とDNDの組み合わせ1つ(+優先のみで通すもの、自動解除、ウィジェットの見た目)。初期プロファイル:

- マナーモード(バイブ + DND優先のみ)
- バイブのみ / ミュートのみ / DND優先のみ(音あり) / 通常

## 機能

- **ウィジェット2種**(どちらもサイズ変更可)
  - トグル(1x1): プロファイル1つをタップでオン/オフ
  - 切り替え(1xN): 選んだプロファイルのボタンを並べ、タップで切り替え。オン中のものをタップで解除
- 「優先のみ」で通すもの(着信・メッセージの相手、メディア、アラーム、システム音)を細かく指定。指定しない項目は**すべてオフ**
- Bluetooth音声機器の接続中だけ「メディア」を許可(切断で自動的に戻す。ヘッドセットのみ/すべて、を選択可)
- 自動解除(30分・1時間・2時間・指定時刻・期限なし・毎回選ぶ)。再起動後も再登録
- オン中は最低重要度・無音の通知(残り時間と「解除」ボタン)
- 解除すると、オンにする前の着信音・DND設定に戻す。任意で音量も復元
- メイン画面はプロファイルの一覧(2つのタブ。タブ名は長押しで変更、「⇒」「⇐」で反対のタブへ移動)。設定は右上の歯車の中(許可・言語・Bluetooth・タブ名・バックアップ・診断)
- プロファイルごとに、解除時の音量の扱い(触れない/元に戻す/決めた音量)を設定
- 全設定のエクスポート/インポート(JSON。プロファイル・画像・タブ名・言語・Bluetooth設定。ウィジェットの配置とオン/オフ状態は含まない)
- アイコンは組み込みのフラットアイコン(16種・色変更可)、絵文字、または好きな画像。背景色・アイコン色・形・大きさ・名前表示を変更可。ダークテーマ対応
- 言語: システム / 日本語 / English(設定で変更)
- 失敗の理由は画面(トースト・「診断」欄)に表示

## 「消音中に音が鳴る」を避ける作り

- 変更前の状態を、何かを変える**前に**保存
- 消音側(着信音)を先に変更し、DNDの後にもう一度確認
- 変更は必ず**読み戻して確認**。少しでも意図より大きな音になっていたら再試行し、それでもだめなら元に戻して理由を表示(「オンになったふり」をしない)
- 外部から端末が変更されていた場合(音量キー等)は、上書きせず「オフ」として扱う(検出はタップ・アプリ起動・自動解除などの時点)
- 通知チャンネルはすべて無音・バイブなし
- Bluetooth切断時は、切断された機器を即座に除外して判定し、メディア許可を外す

## アプリのアイコンを変える

[icon/](icon/README.md) に `icon.svg` または `icon.png` を置いて push すると、ビルド時にランチャーアイコンへ変換されます(失敗しても標準アイコンのままビルドは成功)。

## 権限

| 権限 | 用途 |
|---|---|
| ACCESS_NOTIFICATION_POLICY | DND・着信音の操作(設定画面で許可) |
| BLUETOOTH_CONNECT | ヘッドセット検出 |
| POST_NOTIFICATIONS | オン中の通知 |
| SCHEDULE_EXACT_ALARM | 正確な自動解除(なくても動作し、数分遅れる場合あり) |
| RECEIVE_BOOT_COMPLETED | 再起動後に自動解除を再登録 |

INTERNET権限はありません。データはすべて端末内(SharedPreferencesとアプリ専用フォルダ)です。常駐サービスはありません。

## ビルド

`main` へのpushでGitHub Actionsがデバッグ APKをビルドし、Artifacts に `CorrectModeWidget-build<番号>-debug.apk` を置きます。`docs/`・`*.md`・`*.txt`・`LICENSE` だけの変更ではビルドしません。

APKは**リポジトリ内の固定デバッグ鍵**(`app/debug.keystore`、パスワード `android`)で署名します。そのため更新インストールが毎回できます。**この鍵は公開されているので、配布・リリース用には使わないでください。**
